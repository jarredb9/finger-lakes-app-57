# Containerized iOS PWA Emulation Testing

The application supports standalone progressive web application (PWA) usage across iOS (WebClip) and modern desktop/mobile browsers. To verify mobile standalone behavior and external navigation launches (Issue #63) without requiring physical iOS hardware or macOS simulator licensing, automated PWA tests run via containerized WebKit (Mobile Safari device profile) in Playwright and JSDOM in Jest. Standalone mode is emulated by injecting `window.navigator.standalone = true` and overriding `(display-mode: standalone)` matchMedia queries in targeted test fixtures, verifying transient gesture preservation via native WebKit `popup` event dispatches. Cloud device farms and macOS simulator runners were rejected due to high operational latency, recurring SaaS costs, and incompatibility with local Linux container workflows.
