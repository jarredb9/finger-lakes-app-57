# Transitive Dependency Audit Exception Policy and Toolchain Overrides

Transitive vulnerabilities in development and test toolchains that lack upstream patches and have no exposure to untrusted input are accepted under an audit floor of `--audit-level=moderate`, while patchable transitive vulnerabilities across runtime and toolchain packages are strictly remediated via `package.json` `overrides`. Specifically, `deepmerge@4.3.1` (GHSA-gcqx-w48m-w2h4 / CVE-2026-93753, Low severity) is required by `jest-config` to merge static test configuration objects; upstream has no patched release, replacing it with `deepmerge-ts` breaks Jest's internal `.all()` method contract, and the dependency is never bundled into production client/server code. Simultaneously, patchable transitive vulnerabilities in `glob` (GHSA-3g3m-2fjr-6pw4) and `minimatch` (GHSA-g3hv-75wg-m249) are pinned to patched releases (`glob@^14.0.3` and `minimatch@^11.0.4`) via npm overrides to ensure all Moderate, High, and Critical security findings remain zero across the workspace.
