# Container Runner and Playwright Version Parity Coupling

Playwright E2E and Jest tests execute within container runner scripts (`scripts/containers/`) pinned to Microsoft's official Playwright Ubuntu Noble image (`mcr.microsoft.com/playwright:v<version>-noble`). Playwright enforces strict runtime revision matching between the `@playwright/test` npm package and the browser binaries pre-installed in `/ms-playwright/` inside the container image; any skew causes immediate test execution failure. Because Dependabot cannot coordinate atomic multi-file updates across `package.json`, bash container configurations, and GitHub Actions workflows, `@playwright/test` is excluded from automated Dependabot package sweeps via `.github/dependabot.yml`. Upgrades to Playwright and the canonical container image tag must be performed atomically in dedicated pull requests to maintain environment parity across local RHEL 8 developer workflows and GitHub Actions CI pipelines.
